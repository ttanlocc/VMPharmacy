<objective>
Make order creation atomic using a PostgreSQL RPC function so that order + order_items are inserted in a single transaction. If any part fails, the entire operation rolls back.

Purpose: Prevents orphaned orders (order row without items) which currently happens if the order_items insert fails after the order insert succeeds (SAFE-01).
Output: Migration SQL file + updated POST /api/orders handler.
</objective>
